# A06 Library Service Robot

Project website for IC382 Group A06, published with GitHub Pages at https://icproject2026.github.io.

The site is static: `index.html` plus the `assets/` and `media/` folders. To preview locally, run `python3 -m http.server 8000` in this folder and open http://localhost:8000 (opening the file directly will not load the 3D model).
